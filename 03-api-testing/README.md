# 03 — Testes de API

## Objetivo
Demonstrar testes de API com foco em contrato, regras de negócio, integridade dos dados e tratamento de erros.

## Ferramentas
- Postman;
- Swagger / OpenAPI;
- JavaScript para scripts de teste;
- SQL / PostgreSQL para verificações complementares, quando aplicável.

## Cenários planejados
- [ ] Validar códigos de status e estrutura da resposta;
- [ ] Validar campos obrigatórios, tipos e valores;
- [ ] Validar autenticação e autorização;
- [ ] Testar parâmetros ausentes, inválidos e limites;
- [ ] Validar comportamento para recursos inexistentes;
- [ ] Organizar collection, environments e variáveis;
- [ ] Automatizar verificações e documentar execução.

## Entregáveis
Collection exportável, massa de dados fictícia, instruções de execução e relatório com resultados observados.

**Status:** estrutura inicial criada. Nenhuma API real ou corporativa está incluída.

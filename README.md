# QA Engineering Portfolio

Portfólio técnico com estudos de caso e projetos práticos de **Quality Assurance**, organizado para demonstrar abordagem analítica, estratégia de testes e habilidades técnicas.

> Os materiais deste repositório são demonstrações e estudos independentes. Não representam sistemas, dados, documentos ou resultados internos de empregadores ou clientes.

## Sobre

Sou Analista de Testes de Software Pleno, com atuação em qualidade de software e experiência em planejamento, elaboração e execução de testes. Trabalho com testes funcionais, regressivos, exploratórios, de API e de desempenho, além de automação.

**Principais tecnologias e práticas**
- **Automação:** Playwright com TypeScript; Robot Framework com Selenium
- **API:** Postman, Swagger e JavaScript
- **Performance:** k6
- **Dados:** SQL e PostgreSQL
- **Processos:** BDD, Jira e Scrum

## Como navegar

Cada projeto terá:
1. Objetivo e contexto do cenário;
2. Escopo e estratégia de testes;
3. Ferramentas e pré-requisitos;
4. Como executar os exemplos;
5. Evidências, resultados e análise;
6. Limitações e próximos passos.

## Princípios de qualidade

- Casos de teste claros, rastreáveis e sem redundância desnecessária;
- Cobertura de fluxos positivos, negativos e alternativos;
- Priorização orientada a risco;
- Automação com código organizado e instruções reproduzíveis;
- Resultados apresentados com contexto, sem métricas inventadas.

## Status

Este portfólio está em construção. Os diretórios iniciais organizam os estudos de caso; exemplos executáveis, evidências e resultados serão adicionados conforme cada projeto for desenvolvido e validado.

# Robot Framework + Selenium

## Objetivo
Demonstrar automação de interface usando Robot Framework e SeleniumLibrary.

## Cenários planejados
- Login bem-sucedido;
- Login inválido;
- Validação de mensagens e estados da interface;
- Logout.

## Pontos técnicos a demonstrar
- Separação entre recursos, variáveis e casos de teste;
- Seletores claros e reutilizáveis;
- Configuração headless;
- Evidências e relatórios de execução;
- Gerenciamento de dependências e navegador.

**Status:** plano do estudo de caso; scripts e instruções serão adicionados após validação em ambiente de demonstração.

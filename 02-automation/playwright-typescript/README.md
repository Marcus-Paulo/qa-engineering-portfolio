# Playwright + TypeScript

## Objetivo
Construir uma suíte demonstrativa de testes end-to-end com Playwright e TypeScript.

## Cenários planejados
- Login com credenciais válidas;
- Tentativa de login com credenciais inválidas;
- Validação de campos obrigatórios;
- Encerramento de sessão.

## Organização proposta
```text
playwright-typescript/
├── tests/
├── pages/
├── fixtures/
├── playwright.config.ts
├── package.json
└── README.md
```

## Execução
Os comandos serão documentados após a inclusão do projeto executável e a escolha de uma aplicação pública/de demonstração.

**Status:** plano do estudo de caso; ainda não contém suíte executável.
